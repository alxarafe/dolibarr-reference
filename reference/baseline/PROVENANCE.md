## Generation

Artifacts are generated by `./bin/capture-technical` against a running baseline environment started with `./bin/up`.

The capture process:
1. Reads effective configuration from running containers
2. Fetches the Swagger 2.0 descriptor from `/api/index.php/explorer/swagger.json` using authenticated REST API
3. Normalizes the descriptor (removes environment-dependent `host` field, sorts keys deterministically)
4. Derives an API inventory (method, path, operationId, tags)
5. Extracts technical metadata (versions, modules, database, entity, API configuration)
6. Writes deterministic, version-controlled artifacts

## Regeneration

To regenerate from the same baseline:

```bash
./bin/reset
./bin/up
./bin/capture-technical
```

The output must be bit-for-bit identical to the committed artifacts. Any difference indicates a change in the observable technical contract and must be reviewed before committing.
